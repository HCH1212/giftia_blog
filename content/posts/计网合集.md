## tcp/ip 四层模型
- 应用层：http、dns、ftp
- 传输层：tcp、udp
- 网际层：ip
- 网络接口层：数据链路层(mac)、物理层

## 浏览器输入 url 的整个过程
1. url 解析：生成get请求
2. dns 解析：域名转 ip
3. tcp 三次握手：建立连接
4. tls 四次握手：https
5. 发送请求报文
6. 服务器响应数据
7. 客户端渲染数据
8. tcp 四次挥手：超时或主动关闭

## dns 解析详情
1. 查浏览器 dns 缓存
2. 查操作系统 dns 缓存
3. 查本地 hosts 文件
4. 查本地 dns 服务器缓存
5. 向本地 dns 服务器发起递归查询请求
6. 本地 dns → . 根域名服务器
7. 本地 dns → .com 顶级域名服务器
8. 本地 dns → qq.com 权威域名服务器
9. 本地 dns 拿到 ip 后，返回给浏览器，同时缓存一份以备后续使用

## get 和 post 的区别
- get 请求数据放 query，不能太大；post 请求数据放 body
- get 幂等；post 一般不幂等
- get 会被浏览器缓存
- 都不保证安全

## cookie 和 session
- 让无状态的 http 带上状态
- cookie 存客户端，session 存服务端
- 使用示例：服务端生成 sessionid，客户端请求时通过 cookie 带上（说明是同一个用户）

## http 状态码
- 1xx：需要继续处理
- 2xx：成功
- 301：永久重定向
- 302：临时重定向
- 400：入参错误
- 401：未登录
- 403：登录但无权限
- 404：找不到
- 500：服务端错误
- 502：网关错误
